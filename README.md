## How to Run the Programs

### Prerequisites

- Install a Java Development Kit (JDK).
- Install Visual Studio Code.
- Install the Extension Pack for Java in VS Code.

### Steps

1. Clone or download this repository.
2. Open the required practical folder in VS Code.
3. Open the Java source file you want to execute.
4. Run the program using the **Run** button or the terminal.

For a basic Java program:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the class name containing the `main` method.

For Maven-based practicals, use the commands specified in the relevant project's configuration, such as:

```bash
mvn test
mvn package
```
